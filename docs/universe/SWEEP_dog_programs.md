## (5) CANINE CD7 / CD5 / CD52 REAGENTS
- CD5: validated anti-canine CD5 mAbs exist (clones DH3B, DH13A, Davis lab; de Souza, Fidel, Davis J Vet Diagn Invest 2025-02-05, PMC11803592, read). Used routinely in flow. SKEPTIC NOTE: CD5 loss is the most common aberrancy in canine T-NOS lymphoma: in 310 aberrant-phenotype cases (152 T-NOS) CD5-, CD4-CD8-, CD3- predominated (Celant, Marconato...Comazzi, Vet Sci 2022-04-13, PMID 35448684); in 27-case series CD5- 50% of aberrant T lymphomas (Front Vet Sci 2023, PMID 37908841). So a CD5 binder exists, but CD5 is a lossy target in a large T-NOS fraction.
- CD7: NO anti-canine CD7 clone found (searches: PubMed canine CD7 T-cell lymphoma (0 hits), WebSearch "anti-canine CD7 antibody clone", CD7 absent from the 2025 canine mAb review). Only human CD7 clones surfaced (e.g., 6B7). Cross-reactivity to dog: not shown. => reagent gap persists.
- CD52/alemtuzumab: NOT FOUND (WebSearch only human data; canine CD52 not in the canine mAb review).
- Canine T-lineage CAR (CD5/CD7/CD4 CAR): NOT FOUND. Closest: Hess/NC State BiTE-redirected antiviral T cells (CHF 03007, above). Canine CD4 mAbs (DH29A, LSM12.125, LSM8.538), CD22 (RFB-4 human clone) exist per review. New canine CD94 mAb (Front Vet Sci 2025-11-27, PMC12696703): expanded CD94+ in 2/4 T-CLL.
- Also: canine CD3e rabbit mAb HORCF-CD3.1 (Henan, 2025-12); canine CD19 rabbit mAb HAC19.1 (Henan, 2026-03).

READ-ACROSS (judgement, not sourced as a rule): for dog biologics that reached the conditional licence, the interval from first pilot dog data to conditional licence is roughly 3-8 years; conditional->full 2.5-5.5 years. A canine CAR-T has had ~10 years in dogs without licence. "Near-future" for a canine engager/CAR-T that does not yet exist as a dog molecule = >=7-10 years to a licence; for use in a research/clinical-trial setting (as the user's DSP program would) = the build+IND-equivalent time (~2-4 yr) is the relevant number, not the licence time.
